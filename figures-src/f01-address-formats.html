ISO 20022 · Postal address in a payment message

One address, three formats. Only two have a future.

The same supplier address as it travels to the bank, and the SAP field behind each element.

The formatsWhat the bank receives inside <PstlAdr>

Fully structured
Accepted · the target

Every component in its own element. The format the EPC recommends.

<PstlAdr>
  <StrtNm>Calle Principal</StrtNm>
  <BldgNb>123</BldgNb>
  <PstCd>28001</PstCd>

The rules
1

Town and country are mandatory in both surviving formats. Country is a two-letter ISO code, never a name.

2

Hybrid allows two free-text lines of 70 characters at most. Structured allows none.

3

No repetition. A free-text line must not restate the town or postal code already sent as elements.
